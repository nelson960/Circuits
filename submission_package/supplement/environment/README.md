# Environment Metadata

The original experiments were run in a local Python 3.12 environment with PyTorch and standard scientific Python dependencies.

Included:

- `environment.yml`: Conda environment used by the project.
- `pyproject.toml`: project/package metadata.
- `hardware_note.md`: hardware/runtime scope note.

The submitted claims depend on derived numerical artifacts, not on exact wall-clock runtime. Different accelerator hardware should affect runtime, not the reported compact tables.
